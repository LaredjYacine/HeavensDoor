About Heaven's Door

An AI-powered recruitment matching engine, built for recruiters.

What is Heaven's Door?

Heaven's Door connects candidates and job postings using a hybrid search-and-reasoning pipeline. It combines vector similarity search, full-text (BM25) search, and a tool-using AI agent to understand vague or highly specific hiring queries and return relevant matches — so you can ask in plain English instead of crafting precise SQL filters.

Why recruiters use it

Smart, hybrid search

Semantic meaning + keyword precision are merged for stronger recall across jobs and candidate profiles.

Agentic reasoning

The agent picks the right tool per query: exact job titles, candidate-by-role, hybrid search, or schema lookups — automatically.

Async & scalable

Queries run as background jobs (Celery/Redis), so long searches never block the response, and the system scales with demand.

Reliable by design

Automatic retries with backoff, a fine-tuned fallback model, dead-letter queue for failures, and rate-limited endpoints.

Example queries you can ask

Find me a remote frontend role Show candidates who prefer a data engineer role List full-stack jobs requiring Python and React What jobs match someone with strong communication and leadership skills?

Phrase it like you would to a colleague — Heaven's Door figures out the rest.

How it works

  1. You ask in your own words — POST /agent
  2. Deduplication: each request is keyed so retries don't create duplicate jobs.
  3. Agent runs: a LangGraph agent decides whether to match jobs, match candidates, run a hybrid search, or answer generally.
  4. You get the result: poll GET /result with the returned job id until it resolves.
  5. Failures are handled: retried with backoff, then moved to a dead-letter queue for inspection.
